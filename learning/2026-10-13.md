### Verified Phase 1 SQLite run-record schema

Source of truth: `hiwan_ai/storage.py` (`RunRecord`, `SQLiteRunStore._initialize`, `record_run`, `get_run`) and `hiwan_ai/runtime.py` (`run`). The SQLite table is `agent_runs` and its eight columns are:

| Column | Meaning |
| --- | --- |
| `id` | Auto-incremented record ID |
| `created_at` | UTC record-creation timestamp |
| `identity` | Identity for the agent run |
| `prompt` | Input prompt; potentially sensitive |
| `response` | Agent output; potentially sensitive |
| `tool_used` | Optional name of the tool invoked |
| `tool_result` | Optional tool result; potentially sensitive |
| `status` | Run status, currently recorded as `ok` on the Phase 1 success path |

The default development database path is `~/.hiwan/dev/databases/hiwan.db`, physically outside `~/hiwan-ai`. The real SQLite file and its rows are private runtime data and must **never** be copied into Git or this learning journal.
