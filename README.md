# Hiwan AI OS

Personal-first, local-first AI agent ecosystem.

## Vision

Build a personal AI system that gradually evolves into a family AI system.

The system should preserve user-owned knowledge, memory, learning history, projects, and family information independently from any specific AI model or agent framework.

## Core Principles

1. Local-first for private and long-lived data.
2. Cloud AI is replaceable infrastructure, not the owner of memory.
3. Agent and data are separate.
4. Identity, policy, tools, and data access must be separated.
5. Start simple; add infrastructure only when justified.
6. Build first, learn through implementation.
7. Every important learning step should become durable knowledge.

## Repository

- `apps/` — user-facing applications
- `agents/` — agent implementations
- `learning/` — learning notes and daily logs
- `knowledge/` — durable knowledge
- `memory/` — memory infrastructure and schemas
- `mcp/` — MCP servers and tools
- `experiments/` — prototypes and experiments
- `architecture/` — architecture documentation
- `infrastructure/` — deployment and infrastructure
